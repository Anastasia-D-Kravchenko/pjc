Chapter 1.2 - First C++ programs

Posted Feb 25, 2025
By Filip Kwiatkowski
14 min read

Hello World

After a successful configuration of the tool, it’s worth quickly getting a large dose of practice. Typically, the first thing to do is to tackle the most popular application, which is “Hello World”.

Depending on the edition and configuration of the editor, the project generated by default may contain a differently looking file main.cpp. There is no need to worry about this — just delete the content of the generated file and paste the one presented below.

The first C++ code file we will examine looks as follows:

1
2
3
4
5

#include <iostream>

auto main() -> int {
    std::cout << "Hello World";
}

Compiling and running this resulting application will result in displaying the classic Hello World on the screen. Let’s analyze its elements sequentially:

  1. The most important thing is line number 4. Using a relatively strange syntax, it displays the specified text on the console.
  2. Next in line is the definition of the main() function, which encloses lines from 3 to 5. Just like in Java, the entry point of the program in C++ is the main function. The header auto main() -> int should be read as: I declare (auto)1 main, which is a function without arguments (()), returning (->) int2.
  3. The last interesting piece of code is the first line, #include <iostream>. It pastes the contents of the iostream file into our main.cpp file, which is part of the standard library of the C++ language. It contains, among other things, the object std::cout, which we used to display text on the console.

Displaying text

Text is displayed using the std::cout object. In the near future, it will be replaced by a simpler alternative, so we won’t focus too much on it. However, it’s worth familiarizing yourself with the most basic examples of its usage.

#include <iostream>

auto main() -> int {
    std::cout << "Hello World";
    std::cout << "Hello World";
}

In the above example, we copied a line that displays text, which we’re already familiar with. It’s worth noting that the result of running such code is a single, consecutive line.

Using std::cout << multiple times does not result in displaying multiple lines.

To display text on multiple lines, you need to manually specify where the line should end. You can achieve this by adding a newline character (\n) in the appropriate places:

#include <iostream>

auto main() -> int {
    std::cout << "Hello World\n"; // added \n
    std::cout << "Hello World";
}

In the fourth line of the code shown above, you can see a comment. Just like in Java, C++ supports single-line comments (using // syntax) as well as multi-line comments (using /* */ syntax).

On the Internet, you may come across an alternative way of adding a newline character — using std::endl. However, this is not a recommended approach. Not only does it require more typing, but it also performs additional operations that the programmer may not be aware of3.

When wanting to display a longer text fragment, you can break it down into multiple commands for displaying strings, as presented above, for clarity. The principle of how std::cout works can be best summarized based on the last example of the code, where we see multiple consecutive stream insertion operators (arrows — <<).

Repeated uses of the stream insertion operator (<<) send consecutive text fragments to the screen4.

Naturally, text is not the only thing a programmer may want to display. The std::cout object can also display many other data types, as demonstrated in the following code snippet:

It’s worth noting that displaying boolean values (of type bool) using std::cout results in displaying the numbers 1 and 0 instead of the texts true and false. While it’s possible to change this behavior, it’s neither convenient nor efficient. This is another reason (among those that will be discussed further in this chapter) why we will quickly abandon the use of std::cout.

Reading data

Having mastered the basics of displaying, it’s now time to master the basics of reading data. However, to read data, we need to have a place to store it. We need to have allocated the appropriate space in memory to which we can refer. Variables serve this purpose.

Old and new programming styles in C++

The C++ language has undergone many changes over the years. As part of this subject, an alternative syntax for declaring variables and functions will be presented. The following code listing illustrates this.

1
2
3
4

auto main() -> int {
    int x  = 10;    // 1
    auto y = 10;    // 2
}

In the above example, there is no significant difference between creating variables x and y. Method 1 explicitly specifies the variable type as int, while method 2 deduces this type from the type of the literal (the value 10).

During PJC, we will prefer method 2.

Why? It differs from the Java way and in this example requires more typing. Besides, how do I know what the variable type will be?

Because it’s safer. Sometimes it requires more typing, but sometimes the opposite is true. Nevertheless, it combines safety with consistency (sometimes it has to be used).

It’s also worth noting that an alternative way to write the main() function from the discussed listings resembles the syntax from Java, like this:

1
2
3

int main() {
    
}

Using auto main() -> int { } instead of int main() { } brings fewer benefits than using auto x = 10 instead of int x = 10. However, due to several compelling examples (such as lambdas, which will be discussed in the future), it’s worth considering using the auto syntax within modern C++. This style will be consistently applied during the PJC subject.

However, let’s go back to the example with variables of type int. It’s important to understand the dangers that using the “old” style can entail. The danger here is Undefined Behavior — abbreviated as UB.

Undefined Behavior, colloquially referred to as UB, is something that must be avoided at all costs when programming in C++. A program exhibiting such behavior can literally do anything. UB can affect code executed before it, after it, or even in a completely different file.

An example of UB is reading from an uninitialized variable. The following example of code demonstrates the correct creation and display of a variable of type int:

1
2
3
4
5
6

#include <iostream>

auto main() -> int {
    int x = 10; // using the old style to demonstrate an example
    std::cout << x;
}

However, the next code represents an incorrect creation and display (of an uninitialized) variable:

1
2
3
4
5
6

#include <iostream>

auto main() -> int {
    int x;  // using the old style to demonstrate an example
    std::cout << x;
}

What will the above code display?

A novice C++ programmer may have many potential answers to this question:

  • The number 0.
  • Any number.
  • The text null.
  • The code won’t compile.
  • The code crashes.

All the above answers (except for the one mentioning compilation failure) are correct (although there’s a very small chance of displaying null — it might display any text, although int has nothing to do with (Java’s) null).

Forgetting to initialize a variable is a more common mistake than one might think. Let’s see what happens when we try to make the same mistake using the new style:

1
2
3
4
5
6

#include <iostream>

auto main() -> int {
    auto x;  
    std::cout << x;
}

The above code won’t compile. The auto keyword doesn’t allow variable declaration without initialization, thus protecting the programmer from potential UB.

This is a huge plus. Instead of having a compiling error that can silently break our program, we get a clear compilation error indicating that we forgot to initialize the variable.

When using the auto style, it’s worth presenting a few simple examples of variable initialization:

1
2
3
4
5

auto main() -> int {
    auto x = 0;         // 1
    auto y = int();     // 2
    auto z = int(0);    // 3
}

The above listing illustrates the most common cases of variable initialization in C++ using auto:

  1. The type of variable x is deduced based on the type of the literal 0.
  2. In the case of variable y, we explicitly specify the type. This way, the variable is initialized with the value 0.
  3. For variable z, we also explicitly specified the type, but at the same time, we specified the assigned value. It looks a bit like using a constructor, although nothing of the sort is happening here.

The std::cin object

Now that we know how to create variables, it’s time to read data into the program. For this purpose, the std::cin object will be used. The aforementioned <iostream> header provides it along with the already familiar std::cout. Its usage is very simple, assuming that the syntax for displaying data has already been mastered:

1
2
3
4
5
6
7
8
9

#include <iostream>

auto main() -> int {
    auto number = int();

    std::cout << "Input: ";
    std::cin >> number;
    std::cout << "Output: " << number << '.';
}

Assuming that after running the above code, the user enters, for example, the number 1024, the program will display the following text:

1
2

Input: 1024
Output: 1024.

Depending on the configuration of the environment and operating system, sometimes the console incorrectly displays whitespace characters (e.g., spaces or tabs) when combining them with user-entered data. There is no need to worry about this.

As you can see, reading data is very simple. You just need to create a variable and then use std::cin to input a value into it.

It’s easy to remember the direction of the arrows (<< and >>) by analyzing the objects (e.g., variables). In the case of the fragment std::cout << "Input: ", the text Input: is sent to the output. Hence, the arrows point from it to the standard output. In the case of the fragment std::cin >> number, some data from the input is retrieved and stored in the variable. Hence, the arrows point from the standard input to the variable.

Simple control-flow and mutating operations

The Java language, already familiar from earlier, inherited many syntax elements from C++. This group includes, among others:

  • Selected control operations, such as:
    • if ();
    • while ();
    • do { } while();
    • for ();
    • the ternary operator ? :.
  • Arithmetic operators (+, -, *, /, %), logical (&&, ||, …) and bitwise (&, |, ~, …).

Therefore, we won’t focus on repeating all of these elements. Where the C++ language differs from Java (e.g., the lack of the switch () statement5 or if () with initialization), these differences will be highlighted, provided they are significant for the example.

#include <iostream>

auto main() -> int {
    auto number    = 0;
    auto sum       = 0;
    auto operation = ' ';

    std::cout << "Enter a number: ";
    std::cin >> number;
    sum += number;

    while (true) {
        std::cout << "Enter an operation "
                  << "(+ to add, - to subtract, / to divide, "
                  << "* to multiply, or q to quit): ";
        std::cin >> operation;

        switch (operation) {
            case '+':
                std::cout << "Enter a number to add: ";
                std::cin >> number;
                sum += number;
                std::cout << "Current total: " << sum << '\n';
                break;
            case '-':
                std::cout << "Enter a number to subtract: ";
                std::cin >> number;
                sum -= number;
                std::cout << "Current total: " << sum << '\n';
                break;
            case '*':
                std::cout << "Enter a number to multiply: ";
                std::cin >> number;
                sum *= number;
                std::cout << "Current total: " << sum << '\n';
                break;
            case '/':
                std::cout << "Enter a number to divide: ";
                std::cin >> number;
                if (number != 0) {
                    sum /= number;
                    std::cout << "Current total: " << sum << '\n';
                } else {
                    std::cout << "Cannot divide by zero. Quitting...\n";
                    return 0;
                }
                break;
            case 'q':
                std::cout << "Quitting...\n";
                return 0;
            default:
                std::cout << "Invalid operation. Quitting...\n";
                return 0;
        }
    }
}

It’s worth simply copying the above code, pasting it into a file named main.cpp, and then running it before starting to analyze it. There’s nothing particularly hidden behind it. It serves only as a demonstration of the similarity of basic instructions between Java and C++.

return in main()

Finally, it’s worth noting that the header of the main() function clearly indicates that it returns a value of type int. So where is the return X statement, where X is some number?

Such a statement won’t be found anywhere in the listings above. That’s because in C++, formally specifying the return value is not required. However, this can be very dangerous because in most cases, it results in UB.

There are two exceptions:

  • Functions returning void don’t need to specify the return keyword anywhere (but they can use it — in the form of return; — to terminate the function’s execution early).
  • The main program function (main()), if it doesn’t return any value, defaults to returning 0.

The C++ language allows skipping the return keyword in function definitions. However, if a function returns something other than void and it’s not the main program function, doing so will result in Undefined Behavior (UB).
