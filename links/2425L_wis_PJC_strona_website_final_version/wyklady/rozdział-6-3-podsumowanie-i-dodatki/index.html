Rozdział 6.3 - Podsumowanie i dodatki

Opublikowano Apr 7, 2025
Autor Filip Kwiatkowski
6 min czytania

Do czytania z i zapisywania do plików tekstowych używamy klasy std::fstream

Obiekty typu std::fstream można traktować jako połączenie std::cin oraz std::cout, z tą różnicą, że zamiast wchodzić w interakcję z konsolą, wchodzą w interakcję z plikami. Wspierają << oraz >>, aczkolwiek w przypadku zapisywania do pliku warto rozważyć używanie biblioteki {fmt}.

Do operacji na wielu plikach i folderach używamy narzędzi z std::filesystem

W przypadku gdy interesują nas operacje na wielu plikach, prędzej czy później zapewne będziemy chcieli skorzystać z std::filesystem. Chociażby do iteracji po wszystkich elementach folderu (przy pomocy std::filesystem::directory_iterator).

Podobnie wygląda sytuacja, gdy chcemy operować albo na folderach, albo na metadanych pliku. Zmiana nazwy, przeniesienie, inspekcja czasu ostatniej edycji — to wszystko można osiągnąć dzięki narzędziom żyjącym w przestrzeni nazw std::filesystem.

Operacja czytania ze strumienia zwraca referencję na ten strumień

Operacja std::cin >> someVariable zwraca nam referencję na std::cin. To dlatego możemy łączyć wiele ekstrakcji jednocześnie, np.: std::cin >> x >> y >> z.

Dodatkowo strumienie mogą być konwertowane na wartości logiczne. Zwracają true, jeżeli ostatnia operacja zakończyła się sukcesem. Dzięki temu możemy tworzyć następujące konstrukcje:

Różne opcje otwierania pliku do zapisu

std::fstream w konstruktorze przyjmuje opcjonalnie drugi argument — opcje otwierania pliku. Są to:

  • std::ios::app — przechodź do końca pliku przy każdej operacji zapisywania;
  • std::ios::binary — otwórz plik jako binarny;
  • std::ios::in — otwórz plik do odczytu;
  • std::ios::out — otwórz plik do zapisu;
  • std::ios::trunc — wyczyść plik po otwarciu;
  • std::ios::ate — przejdź do końca pliku po otwarciu (jednorazowo).

Opcje można ze sobą łączyć przy pomocy alternatywy bitowej (|).

Traktowanie std::string jako strumienia danych

Wiemy już, jak sprawdzić, ile linii ma plik — wystarczy policzyć, ile razy uda się wywołać std::getline() z przekazanym strumieniem, który odpowiada za połączenie z plikiem. Wiemy też, jak policzyć, z ilu słów składa się plik — wystarczy zamiast std::getline() użyć operatora ekstrakcji, czyli >>.

Problem pojawia się wtedy, gdy chcemy sprawdzić, ile jest słów w danej linii. W idealnym świecie chcielibyśmy zrobić coś podobnego do:

#include <fstream>
#include <string>

#include <fmt/base.h>

auto main() -> int {
    auto file = std::fstream("data.txt");

    for (auto line = std::string(); std::getline(file, line); ) {
        auto wordsCount = 0;
        for (auto word = std::string(); line >> word; wordsCount++);
        fmt::println(
                "Line \"{}\" contains {} words",
                line, wordsCount
        );
    }
}

Idea jest dosyć prosta — dla każdej linii tworzymy zmienną wordsCount inicjalizowaną zerem, a później w ramach tej linii dla każdego słowa zwiększamy wspomnianą zmienną. Jest tylko jeden problem:

Ten błąd ma jeszcze z kilkadziesiąt dodatkowych linijek, ale nie mają one większego znaczenia. Na szczęście tym razem przydatna informacja jest na samej górze!

Problem polega na tym, że nie da się wykonać operacji >> na dwóch std::stringach. Nie można w ten sposób “wyciągnąć” słowa.

To, czego chcemy, to być w stanie wykonywać operacje strumieniowe na obiektach typu std::string. Skoro z std::cin, std::fstream czy generalnie dowolnego strumienia wejściowego da się wyciągać słowa za pomocą >> (a sam strumień dodatkowo powie nam, czy ta operacja się udała, więc będziemy wiedzieć, kiedy zakończyć próby), to chcielibyśmy, aby taki std::string mógł się zachować jako strumień wejściowy.

Nie jest to jednak możliwe. std::string nie został zaprojektowany w sposób, który mógłby wspierać takie operacje.

Jest jednak inny typ, który może nam pomóc. Skoro chcemy mieć strumień wejściowy (stream) bazujący na stringu, to skorzystamy z std::stringstream:

#include <fstream>
#include <sstream>  // std::stringstream
#include <string>

#include <fmt/base.h>

auto main() -> int {
    auto file = std::fstream("data.txt");

    for (auto line = std::string(); std::getline(file, line); ) {
        auto wordsCount = 0;
        auto lineAsStream = std::stringstream(line);
        for (auto word = std::string(); lineAsStream >> word; wordsCount++);
        fmt::println(
                "Line \"{}\" contains {} words",
                line, wordsCount
        );
    }
}

Line "first line" contains 2 words
Line "second, longer line" contains 3 words
Line "third line" contains 2 words

Sukces! Zamiana linii (line) na strumień zawierający ten sam tekst (lineAsStream) sprawia, że używając tego drugiego obiektu, jesteśmy w stanie wyciągać kolejno słowa z linii.

O std::stringstream można myśleć jak o std::fstream z tą różnicą, że zamiast swoją zawartość mieć w pliku, std::stringstream przechowuje wszystkie dane w pamięci programu.
