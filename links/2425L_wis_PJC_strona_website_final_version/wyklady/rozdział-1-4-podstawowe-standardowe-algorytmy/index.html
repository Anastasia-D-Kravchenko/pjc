Podstawowe standardowe algorytmy

Poznaliśmy już podstawy zmiennych oraz kontenerów. Teraz czas na zapoznanie się z ciekawszymi operacjami na zbiorach danych.

Biblioteki standardowe współczesnych języków programowania są bogate w upraszczające programowanie narzędzia. Najbardziej podstawowe z nich to kontenery / kolekcje i standardowe algorytmy.

Algorytm std::ranges::sort()

Chcąc posortować jakiś kontener w C++, z reguły najlepiej jest zastosować standardowy algorytm std::ranges::sort().

W wielu źródłach w Internecie można znaleźć przykłady użycia algorytmu std::sort() (bez ranges). Jest to stara, stricte gorsza wersja tego narzędzia i nie należy jej stosować.

Przykład jego działania jest bardzo prosty:

#include <algorithm>
#include <iostream>
#include <vector>

auto main() -> int {
    auto vec = std::vector<int>{3, 5, 1, 4, 2};

    std::ranges::sort(vec);

    for (auto element : vec) {
        std::cout << element << ' ';
    }
}

Nie należy pomijać dwóch istotnych szczegółów przy wprowadzaniu tego tematu:

  1. Algorytm sortowania (jak i większość innych algorytmów) jest częścią nagłówka <algorithm>.
  2. Jak to bywa przy domyślnym sposobie porównywania stringów leksykograficznie (w ich przypadku oznacza to porównywanie alfabetycznie), małe i wielkie litery niezbyt dobrze ze sobą współpracują. Zgodnie z tabelą ASCII, tekst "Programowanie" zostanie umieszczony przed tekstem "c++", z uwagi na to, że znak 'P' (wielka litera) znajduje się przed znakiem 'c' (mała litera).

O ile możliwość porządkowania stringów alfabetycznie jest dosyć intuicyjna, to zaskoczeniem może okazać się, że sam tekst też można posortować. W ten sposób porządkujemy litery jakiegoś tekstu:

Na koniec należy zwrócić jeszcze uwagę, że algorytmy standardowe modyfikują oryginalnie przekazany kontener. Częstym błędem jest założenie, że algorytm zwraca nowy, zmodyfikowany obiekt. Tak jednak nie jest. Na ten moment nic pożytecznego nie wyjdzie z próby zapisu zwracanej wartości ze standardowego algorytmu.

Algorytm std::ranges::reverse()

Czasem programistę interesuje odwrócenie jakiejś sekwencji. Na przykład przy sortowaniu danych malejąco, zamiast rosnąco. O ile sortowanie i późniejsze odwrócenie danych jest mniej wydajne od sortowania, które od razu umieszcza dane w docelowej kolejności, na ten moment będzie to prostsze rozwiązanie:

#include <algorithm>
#include <iostream>
#include <vector>

auto main() -> int {
    auto vec = std::vector<int>{3, 5, 1, 4, 2};

    for (auto element : vec) {
        std::cout << element << ' ';
    }
    std::cout << '\n';

    std::ranges::reverse(vec);

    for (auto element : vec) {
        std::cout << element << ' ';
    }
    std::cout << '\n';

    std::ranges::sort(vec);

    for (auto element : vec) {
        std::cout << element << ' ';
    }
    std::cout << '\n';

    std::ranges::reverse(vec);

    for (auto element : vec) {
        std::cout << element << ' ';
    }
}
