Searching for the longest string

Posted Oct 5, 2023
By Filip Kwiatkowski
1 min read
Difficulty

Finding the longest string

In the Box print task, one of the steps was to find the std::string object with the largest number of elements. This could have been accomplished with a loop, but – as we know – using standard algorithms requires less effort and is often more readable (provided we know them).

With slightly more powerful tools at our disposal, this part of the problem can be solved using std::ranges.

Create four namespaces: v1, v2, v3, v4, in which you will implement the printLongestString() function, which will take a std::vector<std::string> as an argument. Each of these functions should display the longest element of the passed vector. In the subsequent implementations, use the algorithms:

  • std::ranges::max()
  • std::ranges::max_element()
  • std::ranges::min()
  • std::ranges::min_element()

Along with the appropriate comparators and/or projections.
