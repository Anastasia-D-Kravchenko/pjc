Changing the content of a file

Posted Oct 20, 2023
By Filip Kwiatkowski
1 min read
Difficulty

Replacing selected parts of the file

Write a function that takes a reference to an object of type std::fstream and a variable of type std::string as arguments. The function should change the content of the file so that every occurrence of a number (not a digit) in it is replaced with the text passed as an argument.

Example:

1
2

123 456 7a9 hello
1 0 0s s0

1
2
3
4

auto main() -> int {
    auto file = std::fstream(...);
    replace(file, "hello");
}

1
2

hello hello 7a9 hello
hello hello 0s s0

Assume that all numbers in the mentioned file are not “larger” than the string used for replacement. In other words, each number in the file consists of a number of digits less than or equal to the number of characters in the passed std::string.

For example, when replacing numbers with the word "hello", we can assume that there are at most five-digit numbers in the file.
