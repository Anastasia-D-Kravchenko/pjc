Searching for a cycle in a graph

Posted Oct 20, 2023
By Filip Kwiatkowski
1 min read
Difficulty

Checking if a graph represented by a map contains a cycle

The following drawing represents a graph:

flowchart LR
    A([A])
    B([B])
    C([C])
    D([D])
    E([E])
    
    A --> B
    A --> C
    B --> E
    E --> C
    C --> D
    D --> B

It should be interpreted as follows:

  • from location A, you can travel to location B;
  • from location A, you can travel to location C;
  • from location B, you can travel to location E;
  • from location E, you can travel to location C;
  • from location C, you can travel to location D;
  • from location D, you can travel to location B.

One of many possible representations of a graph in C++ is a map of locations and their neighbors. Each location is associated with its neighbors. The above graph can be represented using the structure presented in the following listing:

auto graph = std::map<std::string, std::set<std::string>>();
graph["A"] = {"B", "C"};
graph["B"] = {"E"};
graph["C"] = {"D"};
graph["D"] = {"B"};
graph["E"] = {"C"};

for (auto neighbor : graph["A"]) {
    fmt::println("{}", neighbor);
}

The visible loop will display all neighbors of the vertex A, i.e., all locations reachable from point A. Write a function hasCycle() that takes the graph representation discussed above as an argument and checks whether the graph has a cycle.

A graph has a cycle if there is a kind of loop in it, meaning you can go around in circles.

In the graph above, such a cycle exists. You can indefinitely traverse the path B → E → C → D → B → E → C → D → B → E → C → D → B → E → …

Use the Depth-First Search (DFS) algorithm to traverse the graph.
