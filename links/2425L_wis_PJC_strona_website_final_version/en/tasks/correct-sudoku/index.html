Correct sudoku

Posted Oct 10, 2023
By Filip Kwiatkowski
2 min read
Difficulty

Correctly solved Sudoku in a file

Sudoku is a game where numbers from 1 to 9 must be placed in a 9x9 grid in the right way. In each row and each column, each of the numbers (1 - 9) must appear exactly once. By dividing the grid into nine sections consisting of squares arranged in a 3x3 grid, each of these sections must also consist of each of the numbers — without repetitions.

Sudoku in the file is saved in nine lines, where each of them consists of nine numbers separated by single spaces. The considered files are text files.

Write a program that, for a given path to a folder containing text files storing solutions to Sudoku, will create a new text file named solutions.txt in it, where it will place all the names of the mentioned files containing correctly solved Sudoku.
