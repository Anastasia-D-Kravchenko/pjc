Appending elements to containers

Posted Apr 21, 2024
By Filip Kwiatkowski
1 min read
Difficulty

Adding elements to containers using alternative syntax

As you know, to add multiple elements to a container, for example, to std::vector<int>, you need to repeatedly call the appropriate method on it (for a vector, this is .push_back()). For example:

#include <vector>

#include <fmt/ranges.h>

auto main() -> int {
    auto vec = std::vector<int>();

    // getting data from somewhere

    vec.push_back(2);
    vec.push_back(1);
    vec.push_back(3);
    vec.push_back(7);

    fmt::println("{}", vec);
}

1

[2, 1, 3, 7]

Assuming we cannot directly input these data into the vector (meaning we cannot use initializer lists, i.e., {…}) 1, it would be convenient to use a more convenient syntax than repeatedly calling the .push_back() method. For example, like this:

auto main() -> int {
    auto vec = std::vector<int>();

    // getting data from somewhere

    vec += 2, 1, 3, 7;

    fmt::println("{}", vec);
}

1

[2, 1, 3, 7]

Task

Provide the appropriate template operator overload(s) so that elements can be added to any vector using the syntax presented above, i.e., you can call the += operator on such a vector, followed by a series of elements separated by commas.

version

Ensure that:

  • No temporary vectors or other containers are created.
  • The syntax cannot be used in any other, non-intuitive form, for example, through someVector, 1, 2, 3 — it must be += after the container name.

  1. Nor do we want to create a separate temporary container that exists only to call .begin() and .end() on it to add its elements to the vector through a single call to the range overload of the .insert() method. ↩
