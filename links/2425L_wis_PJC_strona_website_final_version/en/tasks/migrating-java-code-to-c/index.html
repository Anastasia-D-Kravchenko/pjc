Implementing the same programs in multiple programming languages

Programming languages are merely tools. There are many of them because different problems require different approaches, architectures, and conveniences. Nevertheless, different languages have common elements. Especially general-purpose languages. In such languages, it’s often possible to achieve the same behavior using different syntax.

To better familiarize yourself with the C++ language, rewrite the following Java programs in C++:

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        String name;

        System.out.print("Input your name: ");
        name = input.next();

        if (name.equals("Einstein")) {
            System.out.println("I know you!");
        } else {
            System.out.println("Greetings.");
        }
    }
}

Pay attention to the differences — C++ doesn’t have Scanner or the .equals() method.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int numberToGuess = (int)(Math.random() * 100);
        int guessedNumber = -1;

        while (guessedNumber != numberToGuess) {
            System.out.print("Guess a number: ");

            guessedNumber = input.nextInt();

            if (guessedNumber > numberToGuess) {
                System.out.println("Too big. Try lower.");
            }
            if (guessedNumber < numberToGuess) {
                System.out.println("Too small. Try higher.");
            }
        }

        System.out.println("Congratulations!");
    }
}

Pay attention to the differences — C++ doesn’t have Math.random(). Use std::rand() for simple randomization1, or the <random> library for finer control over pseudorandom mechanisms.

import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.println("Please input the numbers.");
        System.out.println("Type in a negative number to stop.");

        List<Integer> numbersToCheckForPrimality = new ArrayList<>();

        for (
                int number = input.nextInt();
                number >= 0;
                number = input.nextInt()
        ) {
            numbersToCheckForPrimality.add(number);
        }

        for (int number : numbersToCheckForPrimality) {
            if (isPrime(number)) {
                System.out.println(number + " is prime.");
            } else {
                System.out.println(number + " is not prime.");
            }
        }
    }

    public static boolean isPrime(int number) {
        if (number < 2) return false;
        for (int i = 2; i <= Math.sqrt(number); i++) {
            if (number % i == 0) return false;
        }
        return true;
    }
}

Pay attention to the differences:

  • In C++, there is no List<>s or ArrayList<>s. To create a collection that stores a variable number of elements (since a regular array won’t suffice), one should use std::vector.
  • In C++, helper functions don’t have to be class methods (so you don’t need to use the static modifier).
  • How will you add a new element to a vector?
  • Where will you create a helper function?

  1. std::rand() is a very low-quality pseudo-random number generator. For very simple programs, it can be used, but for sophisticated simulations where we want to draw scientific conclusions, it’s much better to use high-quality components from the <random> library. Unfortunately, this library is very difficult to use for beginners. ↩
