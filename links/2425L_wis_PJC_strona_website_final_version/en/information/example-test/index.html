General test rules

The exam consists of three types of questions:

  • True/False questions — there are 20 of them;
  • Multiple-choice code analysis questions — there are 2 of them;
  • Open-ended questions — there are 4 of them.

In the True/False questions, each statement should be marked as P (true) or F (false). Not answering a question results in 0 points. A correct answer earns 1 point. An incorrect answer deducts 1 point. The total score for this section cannot be less than 0 points (if the score would be less than 0, it is set to 0).

In the multiple-choice code analysis questions, you need to select the single correct answer. Each correct answer is worth 2 points. There are no negative points for this section.

In the open-ended questions, you need to provide a written answer to the question or discuss the given topic. You may, but are not required to, include code snippets. Each open-ended question is worth 4 points. There are no negative points for this section.
