Course rules

Posted Feb 24, 2025
By Filip Kwiatkowski
7 min read

Grade obtaining

The grade is obtained according to the following table:

Achieved pointsGrade
\([0; 50)\)\(2\)
\([50; 60)\)\(3\)
\([60; 70)\)\(3.5\)
\([70; 80)\)\(4\)
\([80; 90)\)\(4.5\)
\([90; 100]\)\(5\)

Additionally, a condition for obtaining a passing grade or higher is to achieve at least 40% of points from each of the three key criteria separately, namely:

  • 40% of the total points from short tests
  • 40% of points from the project
  • 40% of points from the test

However, this means that obtaining exactly 40% in each of these criteria is not enough to pass the course, as the total number of points would then be less than 50. Examples can be found in the section Additional remarks and information.

Points

Points can be earned in four different ways:

  1. Short tests — \([0, 20]\);
  2. Semester project — \([0, 40]\);
  3. Test — \([0, 40]\);
  4. Extra points — \([0, 10]\);

It is possible to earn more than 100 points — after all, bonus points are additional, so they allow exceeding the standard point pool.

Bonus points count towards the total only if, without them, the student would receive at least the grade \(3\) (i.e., earned at least 50 non-bonus points).

Short tests

Short tests cover topics presented in the lecture and practiced in exercises. There is five of them. The short tests are scheduled as follows:

  1. Third laboratories;
  2. Fifth laboratories;
  3. Seventh laboratories;
  4. Ninth laboratories;
  5. Eleventh laboratories;

Short tests are worth 4 points each.

Short tests consist of two tasks — code analysis and code writing. Example short tests can be found in a separate post in the Information section.

The laboratories tutor has up to 14 days to grade a short test.

Each short test lasts up to 15 minutes.

Semester project

Each student is required to independently complete a semester project. Project topics are published around the middle of the semester and are determined by the course instructors. All students have access to the same pool of topics. Each student selects a topic individually. There are no requirements for uniqueness in topic selection — for example, it is possible that all students choose the same topic. There is no need to report the selection to the instructors.

The mandatory, in-person project defense takes place during the 12th or 13th laboratories (as determined by the instructor). The submission deadline for projects will be announced later during the semester — but no later than three weeks after the project topics are published. Projects must be submitted according to the guidelines that will be provided later. Failing the project defense results in earning 0 points for the project.

There is no retake for the project.

The project implementation must compile (and run) on university computers. If the project does not meet this requirement, and if the instructor (with possible student assistance) is unable to fix the issue within a very short time (under 1 minute) during the defense, the project will not be accepted for defense.

Test

The test takes place during the fourteenth (penultimate) exercises.

The example test can be found in the Information section.

The laboratories tutor has up to 6 days to grade Test.

The test can be retaken during the last laboratories. The grade scored during the second attempt will replace the grade scored in the first one.

Extra Points

Extra points are awarded for participation in exercises by the laboratories tutor. Exceptional activity during the lecture or contributing to enhancing course materials may also be rewarded with extra points.

Exam

None. The only grade obtained is the one from the laboratories.

Absences

According to the study regulations, the student is allowed up to 30% absences, with a maximum of half of them being unjustified. Exceeding these limits may result in failing the course.

If a student’s absence during a class where an assessment is made (e.g., a short test or the test) is unjustified, they receive 0 points for that task.

If a student’s absence during a class where a short test is held is justified, they must make up for it at the next class they attend (after providing the appropriate document in a timely manner).

If a student’s absence during a class where the test (or its retake) or project is held is justified, they should arrange with the course instructor the appropriate way to make up for that absence.

Non-independent or dishonest work

If, during the grading of any assignment, the instructor finds that the student’s work was not independent or was dishonest, this may serve as grounds for the student failing the entire course. The same applies if the instructor discovers that the student is retaining information they should not (e.g., taking a photo of a short test or the test).
