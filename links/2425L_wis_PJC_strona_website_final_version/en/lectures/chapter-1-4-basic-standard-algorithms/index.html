Basic standard algorithms

We’ve already covered the basics of variables and containers. Now it’s time to familiarize ourselves with more interesting operations on data sets.

The standard libraries of modern programming languages are rich in tools that simplify the process of application development. The most basic of these are containers / collections and standard algorithms.

std::ranges::sort() algorithm

When it comes to sorting a container in C++, it’s generally best to use the standard std::ranges::sort() algorithm.

In many online sources, you can find examples of using the std::sort() algorithm (without the ranges part). This is an older, strictly worse version of this tool and should not be used.

The example of its operation is very simple:

#include <algorithm>
#include <iostream>
#include <vector>

auto main() -> int {
    auto vec = std::vector<int>{3, 5, 1, 4, 2};

    std::ranges::sort(vec);

    for (auto element : vec) {
        std::cout << element << ' ';
    }
}

#include <algorithm>

#include <string>
#include <vector>

auto main() -> int {
    auto vec = std::vector<std::string>{"programming", "in", "c++"};

    std::ranges::sort(vec);

    for (auto element : vec) {
        std::cout << element << ' ';
    }
}

Two important details should not be overlooked when introducing this topic:

  1. The sorting algorithm (like most other algorithms) is part of the <algorithm> header.
  2. As it is often the case with the default way of comparing strings lexicographically (in their case, this means alphabetically), lowercase and uppercase letters do not mix very well. According to the ASCII table, the text "Programming" will be placed before the text "c++", because the character 'P' (uppercase) comes before the character 'c' (lowercase).

While the ability to alphabetically order strings is quite intuitive, it may be surprising that text itself can also be sorted. In this way, we order the letters of some text:

Finally, it should be noted that standard algorithms modify the container originally passed to them. A common mistake is to assume that the algorithm returns a new, modified object. However, this is not the case. At this point, nothing useful will come out of trying to save the returned value from the standard algorithm.

std::ranges::reverse() algorithm

Sometimes a programmer may be interested in reversing a sequence. For example, when sorting data in descending order instead of ascending order. While sorting and then reversing the data is less efficient than sorting that places the data in the desired order from the start, it will be a simpler solution for now:

#include <algorithm>
#include <iostream>
#include <vector>

auto main() -> int {
    auto vec = std::vector<int>{3, 5, 1, 4, 2};

    for (auto element : vec) {
        std::cout << element << ' ';
    }
    std::cout << '\n';

    std::ranges::reverse(vec);

    for (auto element : vec) {
        std::cout << element << ' ';
    }
    std::cout << '\n';

    std::ranges::sort(vec);

    for (auto element : vec) {
        std::cout << element << ' ';
    }
    std::cout << '\n';

    std::ranges::reverse(vec);

    for (auto element : vec) {
        std::cout << element << ' ';
    }
}
