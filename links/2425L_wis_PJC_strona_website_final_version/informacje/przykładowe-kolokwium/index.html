Ogólne zasady kolokwium

Kolokwium składa się z trzech rodzajów pytań:

  • Pytania zamknięte prawda / fałsz — jest ich 20;
  • Pytania zamknięte z analizą kodu — jest ich 2;
  • Pytania otwarte — jest ich 4.

W pytaniach zamkniętych prawda / fałsz każdy podpunkt należy oznaczyć jako P (prawda) lub F (fałsz). Za brak udzielenia odpowiedzi przyznawane jest 0 punktów. Za poprawną odpowiedź przyznawany jest 1 punkt. Za błędną odpowiedź odejmowany jest 1 punkt. Sumarycznie za to zadanie nie można dostać mniej niż 0 punktów (jeżeli ktoś by miał dostać mniej niż 0 punktów, to wynik jest ustawiany na 0).

W pytaniach zamkniętych z analizą kodu należy zaznaczyć pojedynczą, poprawną odpowiedź. Jest ona warta 2 punkty. Za to zadanie nie ma punktów ujemnych.

W pytaniach otwartych należy słownie odpowiedzieć na pytanie lub omówić dane zagadnienie. Można, ale nie trzeba, dopisywać fragmentów kodu. Każde takie pytanie jest warte 4 punkty. Za to zadanie nie ma punktów ujemnych.

Zadanie 1

Zaznacz P (prawda) lub F (fałsz) w pytaniach poniżej. Prawidłowe odpowiedzi są warte 1 punkt, a błędne odejmują 1 punkt od uzyskanej sumy. Brak odpowiedzi skutkuje uzyskaniem 0 punktów za dane pytanie.

    first oraz second mają różne typy.

  • Metoda .end() zwraca iterator (nie obiekt z kontenera).
  • Używanie inteligentnych wskaźników (np. std::unique_ptr) zawsze prowadzi do wycieków pamięci (ang. memory leaks).
  • Gdy skopiujemy wskaźnik do obiektu typu SomeType, wywołany zostanie konstruktor kopiujący z tej klasy.
  • Następująca implementacja funkcji: auto myFunction() -> int { } poprawnie się skompiluje, ale jej wywołanie będzie skutkowało Zachowaniem Niezdefiniowanym (UB, ang. Undefined Behavior).
  • Gdy do pliku tekstowego zapiszemy następujące wartości typu int: 2137, 420, 1337 i 69 to będzie on zajmował tyle samo bajtów, jak gdybyśmy zapisali do niego wartości: 7312, 240, 7331 i 96.
  • Można przeciążyć operator+ dla dowolnych dwóch typów.

Zadanie 7

Wyjaśnij różnicę w działaniu słowa kluczowego const w kontekście tworzenia:

  • stałego obiektu (auto const variable = …;);
  • stałej referencji (auto const& reference = …;).
