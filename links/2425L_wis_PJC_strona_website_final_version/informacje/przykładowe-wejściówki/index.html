Ogólne zasady wejściówek

Każda wejściówka składa się z dwóch zadań:

  1. Zadanie z interpretacją krótkiego kodu;
  2. Zadanie z napisaniem krótkiego kodu.

Jeżeli nie napisano inaczej, należy założyć, że kod z zadania traktującym o czytaniu kodu poprawnie się kompiluje. Dodatkowo bardzo często będą pomijane #includey ze względu na chęć oszczędzenia miejsca. Należy założyć, że wszystkie wymagane dyrektywy #include są obecne. Gdy w listingu nie ma funkcji main(), należy założyć, że cały listing to jej ciało.

Zadanie 2

Napisz funkcję, która przyjmie przez argument tablicę 9 liczb (std::array<int, 9>). Wyświetl tak, jeżeli dzieląc ten ciąg na trzy trójki (pierwsze trzy liczby, drugie trzy liczby i trzecie trzy liczby), wszystkie z nich składają się z tych samych liczb. W przeciwnym przypadku wyświetl nie. Zignoruj kolejność w ramach tych grup.

struct Base {
    virtual auto method() const -> void {
        fmt::println("Base");
    }
};

struct Derived : Base {
    auto method() const -> void override {
        fmt::println("Derived");
    }
};

auto byReference(Base& base) -> void { base.method(); }
auto byCopy(Base base) -> void { base.method(); }

auto main() -> int {
    auto derived = Derived();
    auto base    = Derived();
    byReference(derived);
    byReference(base);
    byCopy(derived);
    byCopy(base);
}
