Chapter 6.3 - Text files

Posted Apr 7, 2025
By Filip Kwiatkowski
6 min read

For reading from and writing to text files, we use the std::fstream class

Objects of type std::fstream can be thought of as a combination of std::cin and std::cout, with the difference that instead of interacting with the console, they interact with files. They support << and >>, although when writing to a file, it’s worth considering using the {fmt} library.

For operations on multiple files and folders, we use tools from std::filesystem

When operations on multiple files are of interest, sooner or later we’ll probably want to use std::filesystem. For example, for iterating through all items in a folder (using std::filesystem::directory_iterator).

The situation is similar when we want to operate on either folders or file metadata. Renaming, moving, inspecting the last edit time — all of this can be achieved using tools living in the std::filesystem namespace.

Reading from a stream operation returns a reference to that stream

The operation std::cin >> someVariable returns a reference to std::cin. That’s why we can chain multiple extractions simultaneously, e.g., std::cin >> x >> y >> z.

Additionally, streams can be converted to logical values. They return true if the last operation was successful. This allows us to create the following constructs:

if (std::cin >> someInt) {
    fmt::println("Successfully read an int");
}

Or:

if (someFstream >> someInt) {
    fmt::println("There was an int in a file with value {}", someInt);
}

Different options for opening a file for writing

std::fstream optionally accepts a second argument in its constructor — file opening options. These are:

  • std::ios::app — go to the end of the file on each write operation;
  • std::ios::binary — open the file as binary;
  • std::ios::in — open the file for reading;
  • std::ios::out — open the file for writing;
  • std::ios::trunc — clear the file after opening;
  • std::ios::ate — go to the end of the file after opening (once).

Options can be combined using the bitwise OR (|) operator.

Treating std::string as a data stream

We already know how to check how many lines a file has — just count how many times you can call std::getline() with the stream associated with the file. We also know how to count how many words are in a file — simply use the extraction operator >> instead of std::getline().

The problem arises when we want to check how many words are in a given line. In an ideal world, we would like to do something like:

#include <fstream>
#include <string>

#include <fmt/base.h>

auto main() -> int {
    auto file = std::fstream("data.txt");

    for (auto line = std::string(); std::getline(file, line); ) {
        auto wordsCount = 0;
        for (auto word = std::string(); line >> word; wordsCount++);
        fmt::println(
                "Line \"{}\" contains {} words",
                line, wordsCount
        );
    }
}

The idea is quite simple — for each line, we create a variable wordsCount initialized to zero, and then within that line, for each word, we increment the mentioned variable. There is just one problem:

This error has a few dozen additional lines, but they are not of great importance. Fortunately, this time the useful information is at the very top!

The problem is that it’s not possible to perform the >> operation on two std::strings. You can’t “extract” words this way.

What we want is to be able to perform stream operations on objects of type std::string. Since with std::cin, std::fstream, or generally any input stream, we can extract words using >> (and the stream itself will additionally tell us whether this operation was successful, so we will know when to stop trying), we would like such a std::string to behave as an input stream.

However, this is not possible. std::string was not designed in a way that could support such operations.

However, there is another type that can help us. Since we want to have an input stream based on a string, we will use std::stringstream:

#include <fstream>
#include <sstream>  // std::stringstream
#include <string>

#include <fmt/base.h>

auto main() -> int {
    auto file = std::fstream("data.txt");

    for (auto line = std::string(); std::getline(file, line); ) {
        auto wordsCount = 0;
        auto lineAsStream = std::stringstream(line);
        for (auto word = std::string(); lineAsStream >> word; wordsCount++);
        fmt::println(
                "Line \"{}\" contains {} words",
                line, wordsCount
        );
    }
}

Line "first line" contains 2 words
Line "second, longer line" contains 3 words
Line "third line" contains 2 words
Line "fourth line - the longest so far" contains 7 words

Success! Converting a line (line) to a stream containing the same text (lineAsStream) allows us to extract words from the line sequentially using this second object.

You can think of std::stringstream as std::fstream, with the difference being that instead of its content being in a file, std::stringstream stores all data in the program’s memory.
